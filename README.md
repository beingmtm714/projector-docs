# Projector public documents

Read the [Projector workroom](https://beingmtm714.github.io/projector-docs/) without a GitHub account.

- [Product spec](https://beingmtm714.github.io/projector-docs/docs/product-spec.html)

Michael publishes reviewed copies here. The private `beingmtm714/projector` repository holds the complete spec and engineering agreement. This public spec omits compensation and contract execution details. Anyone can read this repository and site.

Run `python3 tools/build-docs.py` to generate the document pages from `docs/`. GitHub Actions publishes the committed `site/` folder after a push to `main`.

To update a document, prepare a public copy, review the Markdown, regenerate the pages, and review the generated output before pushing. Do not sync files from the private repository without reviewing their contents. Do not copy the SOW, backups, credentials, or private history here.
